# TailTreats – Front-End Project

## Project Description

This was my first project during my studies, focused on developing an interactive and responsive website using **HTML, CSS, and JavaScript**.

The main focus was on creating a user-friendly interface, implementing interactive features, and optimizing the website for different screen sizes. Attention was also given to performance, accessibility, and SEO through Google Lighthouse optimizations.

## Live Demo

**[View the website](https://pncgrc.github.io/)**

## Features

- **Product Page:** Add products to a shopping cart, with accurate quantity management and total price calculations.
- **Product Detail Page:** Users can write and submit product reviews.
- **Contact Page:** Interactive map integration using [Leaflet](https://leafletjs.com/). The contact form is currently non-functional.
- **Customer Page:** Retrieve and display customer data through an API call.
- **Responsive Design:** Adapts to different screen sizes, from mobile devices to desktop computers.
- **Performance Optimization:** Improvements based on Google Lighthouse audits.
- **User Experience:** Focus on intuitive navigation and a clear, user-friendly interface.
- **SEO:** Optimizations to improve the website's structure and search engine visibility.

## Technologies Used

- **HTML5** – Structuring web pages
- **CSS3** – Styling and responsive layouts
- **JavaScript** – Interactive features and data processing
- **Leaflet** – Interactive map integration
- **REST API** – Retrieving and displaying customer data
- **Google Lighthouse** – Auditing performance, accessibility, best practices, and SEO
- **GitHub Pages** – Website hosting

## What I Learned

This project was my first practical introduction to front-end web development. It allowed me to gain experience with:

- Structuring web pages with HTML and styling them with CSS.
- Implementing interactive functionality using JavaScript.
- Building a shopping cart with quantity management and price calculations.
- Fetching and processing external data through an API.
- Integrating interactive maps using Leaflet.
- Developing responsive websites for different devices.
- Analyzing and improving website quality using Google Lighthouse.

## Project Goal

The goal of this project was to apply the fundamentals of front-end web development in practice and build an interactive website that combines functionality, usability, and responsive design.
